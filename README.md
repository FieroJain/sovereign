# 📖 Overview

Modern enterprises are rapidly deploying autonomous AI agents capable of:

- Reading emails
- Accessing internal databases
- Managing sensitive files
- Executing workflows
- Communicating with APIs
- Making operational decisions

But there is a critical problem:

> AI agents today operate with enormous privileges and almost zero behavioral security monitoring.

A single prompt injection or malicious instruction can:

- Leak credentials
- Exfiltrate enterprise data
- Delete records
- Escalate privileges
- Manipulate workflows
- Spread compromise across agents

---

# 🚨 The Problem

Traditional security systems rely on:

- Static rules
- Keyword filtering
- Blacklists
- Signature matching

These approaches fail against:

- Subtle prompt injections
- Behavioral manipulation
- Contextual attacks
- Zero-day agent exploits
- AI-generated attack mutations

Most enterprise AI systems today are essentially **unguarded autonomous employees**.

---

# 🛡️ The Solution — SOVEREIGN

**SOVEREIGN-A** acts as an **AI Immune System** for enterprise agents.

Instead of looking for keywords, it learns the:

# 🧬 Behavioral DNA of Every AI Agent

Using **IsolationForest machine learning**, SOVEREIGN-A models normal behavior patterns from historical activity.

The moment an agent behaves abnormally:

- The anomaly is detected
- The attack is isolated
- The attacker is trapped
- The exploit is reverse-engineered
- New defensive mutations are generated
- Protection is deployed pre-emptively
- The system retrains itself permanently

# 📦 Installation

## Prerequisites

- Python 3.11+
- pip
- Gemini API Key *(optional)*

## Clone Repository

```bash
git clone https://github.com/FieroJain/sovereign.git
cd sovereign
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Configure Environment Variables

```bash
cp .env.example .env
```

Add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

## Run Application

```bash
streamlit run app.py
```
